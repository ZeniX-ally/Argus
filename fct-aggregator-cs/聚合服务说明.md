# Argus 聚合服务 v3.4.4 使用说明

## 这是什么
多机台 FAIL 聚合服务：接收各机台实时推送的失败数据，用浏览器打开 Web 看板即可查看
各机台在线状态和 FAIL 明细，支持 XML 报告下载、文件浏览和 CSV 导出。
本包是**纯净聚合包**，只含聚合服务相关文件；机台采集软件是另一个包（机台端包），不要装混。

> v3.4.2 起，聚合看板也已**内嵌进机台主程序**：任何机台侧边栏「工具箱 → 聚合看板」（Ctrl+9）
> 都能直接点开看板窗口，切走后台继续收数据。如果不想装纯净聚合包，直接升级机台包即可。
> v3.4.4 起，Web 看板新增**「设置」页签**（管理后台）：端口/令牌/飞书告警/汇总间隔/
> 传输通道/目录白名单全部可视化开关，不用再手改 config.json。

## 一键部署（推荐）
1. 解压本包到聚合机台（任意目录，如 `D:\ArgusAgg`）
2. 双击「一键部署聚合服务.bat」，UAC 弹窗点"是"
3. 自动完成：
   - 生成 `config.json`（已存在则保留现有配置，不覆盖）
   - 防火墙放行 8080 端口（规则名 `ArgusAggWeb`）
   - 添加开机自启（启动文件夹快捷方式，不写注册表，杀软不会误报）
   - 启动聚合服务（后台无窗口常驻）
4. 部署窗口会打印访问地址，用浏览器打开 `http://本机IP:8080/` 即可查看看板

## 手动启动与停止
- 启动：双击 `Argus.exe`，或命令行运行 `Argus.exe agg --web`（前台常驻）
- 停止：关闭窗口，或按 Ctrl+C
- 查看服务状态：浏览器打开 `http://127.0.0.1:8080/api/health`
- 数据在 `data\`（聚合库 agg_center.db），运行日志在 `logs\`

## 机台端怎么接入
在每台机台的 `config.json` 里加以下三项（其余配置保持不动），然后重启机台软件：

```json
{
  "agg_enabled": true,
  "agg_transport": "http",
  "agg_http_url": "http://聚合机台IP:8080/"
}
```

把 `聚合机台IP` 换成部署本服务的机器 IP（端口若改过，和 `agg_http_port` 保持一致）。
配好后，机台每出一条 FAIL 就会实时推送到聚合服务；断网会自动缓存、恢复后补推，不用人工干预。

> **更简单的做法（v3.4.4）**：机台主程序底部状态栏点「聚合设置」→ 填聚合端 IP 和端口 →
> 点「连接」即可，不用手改 config.json，推送器自动重启生效。

## 文件浏览 / 下载说明
- Web 看板顶部有「看板 | 文件」页签：文件页可以浏览和下载测试报告（XML）
- `config.json` 里的 `results_root`（默认 `D:\Results`）是**文件白名单根目录**：
  XML 报告下载和文件浏览都只能看这个目录里的文件，目录之外一律拒绝（返回 403）
- 要改目录：改 `config.json` 的 `results_root`，然后重启聚合服务

## 可选：访问令牌（agg_token）
产线内网人多想加个锁时，聚合端和每台机台的 `config.json` 配**同一串** `agg_token`：
- 机台端：配好后推送自动带令牌，不用管
- 浏览器访问：地址栏加 `?token=同串`，如 `http://192.168.1.100:8080/?token=abc123`
- 不匹配/不带的一律 403；不配 = 不鉴权（兼容旧部署）

## 可选：飞书离线告警 + 定时汇总（v3.4.3）
聚合端 `config.json` 配 `agg_webhook_url`（飞书群机器人 webhook）后：
- 机台离线（心跳超时 90s）→ 飞书群即时告警卡（机台名 + 最后确认时间，同机台 10 分钟防抖）
- 每 `agg_summary_minutes`（默认 60）分钟 → 各机台汇总卡（在线/离线、累计 FAIL、心跳时间）

## 可选：跨机台 XML 报告下载（v3.4.3）
机台端推送 fail 时自动把 ≤512KB 的 XML 一并上送，聚合端存 `data\agg_xml\{机台}\{seq}.xml`，
Web 看板「报告」列可直接下载**任意机台**的 XML（不再只限聚合机本机）。
超过 512KB 的报告仍走聚合机本机 results_root 白名单下载。

## 常见问题
| 问题 | 原因 / 处理 |
|---|---|
| 浏览器打不开看板 | 服务没启动：重新双击一键部署 bat，或手动运行 `Argus.exe agg --web` |
| 办公室电脑访问不到 | 防火墙未放行，或部署时没以管理员运行：重新双击一键部署 bat（UAC 点"是"） |
| 端口被占用 | 改 `config.json` 的 `agg_http_port`（如 8081）后重启服务，防火墙规则会自动按新端口重建 |
| 某台机台数据一直不出现 | ①机台能 ping 通聚合机台 IP ②`agg_http_url` 的 IP/端口填对 ③聚合服务已启动 ④重启机台软件 |
| 文件页看不到 / 下载 403 | 目标文件不在 `results_root` 目录内，聚合服务只放行白名单目录 |
