# FCT 数据聚合软件 更新说明（2.1.0）

## 本次新增

### 1. FAIL 记录查看
- 底部新增「FAIL记录」页，列出本机所有 FAIL 产品：SN、第一个失败项、型号、测试时间。
- **双击任意一行**，弹出该产品的测试报告：上方是 SN / 型号 / 机台 / 总体结果 / 时间，
  下方是**这台产品的完整测试流程（全部测试项）**，失败的项标红。
  这样可以直接看出失败发生在流程哪一步、前后项的测量值是否也异常。

### 2. 维修记录可以导出了
- 维修记录页新增「导出」按钮，可选 **Excel (.xlsx)** 或 **CSV**。
- 导出的是**当前筛选的记录**（例如先筛「待处理」，导出的就是待处理的那些）。
- 导出列：ID、故障项目、设备型号、设备SN、故障描述、严重度、状态、维修人、维修措施、备注、创建时间。
  严重度和状态导出为中文，Excel 打开中文不乱码。
- 导出完成后可直接选择打开文件。

### 3. 其它
- 新增维修记录时可以手动指定「记录日期」（不再固定为录入时间）。
- 窗口标题显示版本号，方便确认机台上装的是哪一版。

## 升级方法

用新包覆盖原程序文件即可，**保留原来的 `config.json` 和 `data` 文件夹**（历史数据不会丢）。
覆盖前请先退出软件。

# FCT 数据聚合软件 更新说明（2.0.0）

## 程序变化

- 软件用 C# 重新开发，体积从 129MB 缩减到 1.2MB。
- 运行需要机台安装 .NET 8 运行环境（一次性安装）。

## 功能更新

- 修复了 XML 测试文件的解析，可正确读取机台产生的数据。
- 修复了设备状态页读取 FCT.ini 的问题，配置文件被测试软件占用时也能正常读取。
- 修复了当日数据统计，当天的 PASS / FAIL / 中断数量统计准确。
- 良率统计口径：PASS /（PASS + FAIL），中断不计入。
- 产品总数按 SN 去重统计，另外单独显示扫描到的 XML 文件总数。

## 界面更新

- 主页日志窗口放大（占 80%），扫描时可逐条查看每个文件的处理进度，统计数字实时增长。
- 状态栏改为带状态指示灯的显示。
- 设备状态页重新排版，一屏显示全部内容，无需滚动，刷新不闪烁。
- 日志窗口显示启动后的完整日志，实时更新。

## 保留功能

实时监控、历史数据扫描、结果分类统计、FAIL 飞书告警（含失败项明细）、设备状态查看、维修记录、调试工具、开机自启、单实例运行、机台号自动识别。

## 移除功能

- Excel 日报生成。
- 多机数据汇总。

## 部署

机台安装 .NET 8 运行环境后，解压软件包，配置好机台号、结果目录、飞书群地址，双击运行。开机自启在调试页面手动开启。
