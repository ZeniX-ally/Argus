# FCT-Aggregator v2.9.1 —— 更新包（覆盖用）

这个包里 **只有程序文件**，故意不放 `config.json`、不放 `data\`、不放 `logs\`。
所以可以直接整包覆盖到机台的程序目录，**不会动到你现场的配置和历史数据**。

## 覆盖步骤

1. 退出正在运行的 FCT-Aggregator（**右下角托盘图标也要退干净**，否则 dll 被占用会复制失败）
2. 把本包里的文件**全部覆盖**到机台程序目录（原 `config.json`、`data\`、`logs\` 原样保留）
3. 双击 `FCT-Aggregator.exe` 启动；或用 `启动.bat`（走 `dotnet FCT-Aggregator.dll`，规避对无签名 exe 的静态查杀）
4. 确认窗口标题是 `Zenix-Ally | FCT-Aggregator v2.9.1`

## 首次启动会自动做两件事

1. 建两张小表：`todo_items`（待办登记表）、`app_meta`（同步水位线）
   —— 都是 `CREATE TABLE IF NOT EXISTS`，**不动任何历史数据**
2. 把**近 30 天**的不良登记成待办（同类测试项自动合并成大项）

> 老库里 30 天以前的不良**不会**被登记进待办 —— 这是有意的，否则跑了半年的机台会刷出上百张卡。
> 需要往前多扫，在 `config.json` 里写 `"todo_scan_days": 60` 再启动。

## 本次改了什么

**五个软件合成一个 exe，且四个工具直接内嵌成主窗口的页面**：
点左侧「数据分发 / FAIL 排行 / 取数打包 / TDMS 波形」就在当前窗口换页，不再弹新窗口
（需要单独开窗仍可用 `FCT-Aggregator.exe distribute` 之类）。
主窗口默认尺寸因此提到 1360×920。
覆盖后请把机台上原来那 4 个 exe 及目录删掉。包里新增 `TDMSReader.dll`。

以下为早前版本引入、本版沿用：

**界面重新排版**（纯 UI 改动，数据与逻辑一行没动）：

1. 左侧一列导航（总览 / 待办·维修 / FAIL / 设备 / 调试），**「待办·维修」带红色数字角标**
2. 顶部状态改成彩色小胶囊；底部新增常驻状态栏；Ctrl+1~5 切页、Ctrl+R 刷新
3. 总览页做成 KPI 看板（产品数 / PASS / FAIL / 良率 / 待办 + 今日四项），日志区更大

以下为早前版本引入、本版沿用：

1. **单击卡片弹详情预览**：卡片放不下的完整内容都在里面，文字可选中复制；双击仍是确认/编辑
2. **合并的 fail 项在卡片和预览上同时显示**：卡上列前两项 + `+N 项`，预览里列全部并带各自次数

以下为 v2.6.0 引入、本版沿用：

1. **待办只扫近一个月**（`todo_scan_days`，默认 30）
2. **同类测试项自动合并成大项**：`6.1.1.1 5V_Rail` / `6.1.1.2 5V_Rail`、`..._CH1` / `..._CH2`
   合成一张卡；但 `5V` 与 `12V`、`100ms` 与 `200ms` **不会**被错并
3. **一旦登记就永久保留**：过了 30 天窗口卡片仍在，直到被处理完（拖到「已完成」）
4. **可选时间区间**：近 7 天 / 近 30 天 / 近 90 天 / 全部 / 自定义，卡片同时显示「区间内 X 次 · 累计 Y 次」
5. **按 fail 次数排优先级**：列顶就是最该先修的，卡片标注 高 / 中 / 低

详见同目录：

- `版本更新说明.md` —— 面向使用（怎么点、看什么）
- `更新日志.md` —— 面向技术（改了哪些文件、为什么这么设计、踩了什么坑）

## 上线前建议做一次

【调试】页 → 【合并预览】：会打印「你这台机器上的故障项会被归成哪些大项」，
确认没有把不该合的合在一起（各厂命名习惯不同）。同页还有【待办同步】可手动触发一次。

## 桌面提示（v2.5.0 起，可选配置）

默认开启，间隔 15 秒。要调就在 `config.json` 里加：

```json
"desktop_notify": true,
"notify_min_interval_sec": 15,
"todo_scan_days": 30
```

装机后建议在【调试】页点一次【桌面提示测试】，确认 Windows 没把通知屏蔽
（系统设置 → 系统 → 通知 / 专注助手）。

## 注意

- 如果你把这个包解压到**空目录**里直接跑，因为没有 `config.json`，程序会用默认配置启动
  并在日志里记一条 `config.json 未找到(使用默认配置)` —— 那不是故障，但机台上请务必覆盖到原目录。
- 需要**全新安装**（含 config.json 模板）请用 `FCT-Aggregator-v2.9.1.zip`。
