# Argus v3.2.1 —— 更新包（覆盖用）

## 本次变化（v3.2.0 → v3.2.1，安全修复）

- **CSV 导出防公式注入**：FAIL 排行 / 维修记录导出报表时，以 `=` `+` `-` `@` 开头的数据
  自动转成纯文本，防止 Excel/WPS 打开时把恶意内容当公式执行
- **飞书 webhook 只允许 https**：误配 http 会拒绝发送并记日志（不泄露 token）
- **清理残留配置**：`api_key` / `cleanup_admin_key` / `api_host` / `api_port` 四个死字段已从
  配置文件删除（接口早已下线，删除只影响旧版误导，不影响任何现有功能）

这个包里 **只有程序文件**，故意不放 `config.json`、不放 `data\`、不放 `logs\`。
所以可以直接整包覆盖到机台的程序目录，**不会动到你现场的配置和历史数据**。

## 覆盖步骤

1. 退出正在运行的 Argus（**右下角托盘图标也要退干净**，否则 dll 被占用会复制失败）
2. 把本包里的文件**全部覆盖**到机台程序目录（原 `config.json`、`data\`、`logs\` 原样保留）
3. 双击 `Argus.exe` 启动；或用 `启动.bat`（走 `dotnet Argus.dll`，规避对无签名 exe 的静态查杀）
4. 确认窗口标题是 `Argus | FCT 工具套件 v3.2.1`（启动时会先闪过品牌动画，属正常现象）

> 数据库无需迁移：本次修复不动数据库结构，老库直接继续用。

# Argus v3.1.0 —— 更新包（覆盖用）

## 本次变化（v3.0.1 → v3.1.0）

- **开启动画**：启动时播品牌动画（素材已编译进程序，无需额外文件）
- **主页改版**：顶部 5 张今日大卡（产品数/PASS/FAIL/良率/中断）+ 下方累计 3×2 大数字格；实时日志区移到调试工具页
- **FAIL 记录页**：树形/表格双视图一键切换，右上角搜索框即时过滤（失败项/SN/型号），高频失败项标红提醒
- **拖动流畅性**：修掉窗口拖动卡顿/拖不动的问题；待办看板自动刷新加了节流
- **TDMS 工具**：可隐藏通道树、收起数据/属性面板，看波形更大

窗口默认尺寸变大到 1408×768，屏幕更小的机台自动收窄，**无需手动调整**。

这个包里 **只有程序文件**，故意不放 `config.json`、不放 `data\`、不放 `logs\`。
所以可以直接整包覆盖到机台的程序目录，**不会动到你现场的配置和历史数据**。

## 覆盖步骤

> 升级前请确认：v3.1.0 的防重复开启机制与旧版一致（`Global\Argus_SingleInstance`），
> 旧版程序在跑时新版会提示「程序已在运行」—— 先退出旧版再覆盖。

1. 退出正在运行的 Argus（**右下角托盘图标也要退干净**，否则 dll 被占用会复制失败）
2. 把本包里的文件**全部覆盖**到机台程序目录（原 `config.json`、`data\`、`logs\` 原样保留）
3. 双击 `Argus.exe` 启动；或用 `启动.bat`（走 `dotnet Argus.dll`，规避对无签名 exe 的静态查杀）
4. 确认窗口标题是 `Argus | FCT 工具套件 v3.1.0`（启动时会先闪过品牌动画，属正常现象）

## 首次启动会自动做两件事

1. 建两张小表：`todo_items`（待办登记表）、`app_meta`（同步水位线）
   —— 都是 `CREATE TABLE IF NOT EXISTS`，**不动任何历史数据**
2. 把**近 30 天**的不良登记成待办（同类测试项自动合并成大项）

> 老库里 30 天以前的不良**不会**被登记进待办 —— 这是有意的，否则跑了半年的机台会刷出上百张卡。
> 需要往前多扫，在 `config.json` 里写 `"todo_scan_days": 60` 再启动。

## 桌面提示（v2.5.0 起，可选配置）

默认开启，间隔 15 秒。要调就在 `config.json` 里加：

```json
"desktop_notify": true,
"notify_min_interval_sec": 15,
"todo_scan_days": 30
```

### ⚠ 装机必做：先确认 Windows 没把通知关掉（2026-07-31 实测踩到）

开发机上实测出一个**静默失效**的坑：系统把通知总开关关掉后，
`ShowBalloonTip()` **不报错、不抛异常**，程序日志全绿、【调试】页也会显示「已发送一条桌面提示」，
**但屏幕上永远不会出现任何东西**。不先查这一项，你会以为报警在工作。

每台机台、**每个登录账户**都要确认一次（这是 per-user 设置，不跟程序走）：

```powershell
# 查：返回 0 就是被关了；返回 1 或报「属性不存在」都正常
Get-ItemProperty 'HKCU:\Software\Microsoft\Windows\CurrentVersion\PushNotifications' -Name ToastEnabled

# 改（等价于：设置 > 系统 > 通知和操作 > 「获取来自应用和其他发送者的通知」打开）
Set-ItemProperty 'HKCU:\Software\Microsoft\Windows\CurrentVersion\PushNotifications' -Name ToastEnabled -Value 1 -Type DWord
# 改完重启一下通知服务（不行就重启 explorer.exe 或注销重登）
Get-Service WpnUserService* | Restart-Service -Force
```

同时要看的还有：**专注助手 / 勿扰模式**是否开着；
`HKCU:\...\Explorer\Advanced\EnableBalloonTips` 是否为 0。

确认方式：【调试】页 → 【桌面提示测试】，**人眼盯右下角**看到才算通。
页面里写「已发送」**不能**当作验收依据。

### ⚠ 若机台把 `skip_historical_scan` 设成了 `true`

待办登记挂在「历史扇描完成后」这个时机上。跳过历史扇描时，
**老库里的历史不良不会被登记进待办**（新不良不受影响，走实时那条路）。
升级后到【调试】页点一次【待办同步】即可补齐。
两条路径都已用 `tools\upgrade_drill.ps1` 实测过。

## 注意

- 如果你把这个包解压到**空目录**里直接跑，因为没有 `config.json`，程序会用默认配置启动
  并在日志里记一条 `config.json 未找到(使用默认配置)` —— 那不是故障，但机台上请务必覆盖到原目录。
- 需要**全新安装**（含 config.json 模板）请用 `Argus-v3.0.0.zip`。
- 数据分发器是**另一个包** `FCT-Distributor-v1.9.0.zip`，与本包互不影响、各自独立更新。
