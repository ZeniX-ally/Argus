## 3. 解读与建议

- **典型产线规模（中）**：约 **304 ms** / 80 线 / 190 PASS——在后台线程完成，切页不卡；首次进分析页会有短暂「空图→出图」。
- **上限压力（大）**：约 **1593 ms** / 200 线 / 400 PASS——建议用「近 30/90 天」窗口而非「自动」全量，或等 PASS 数 <300 时再开全窗口。
- **UI 线程原则**：v3.35.3 起分析/FAIL/自学习的数据库读取均在 `Task.Run` + `BeginInvoke` 回写，主线程仅做绘制。
- **折线图绘制**：测项 >60 时自动隐藏散点、降低线宽与透明度，减轻 GDI+ 重绘成本（绘制仍在 UI 线程，测项极多时缩放窗口可体感更顺）。
- **刷新节流**：分析页 `Refresh2` 默认 2.5s 内不重复拉数；用户点「刷新」可 `force` 跳过。
- **若仍慢**：优先查杀毒实时扫描 `fct.db`、磁盘是否为机械盘；测量缓存行数见分析页自学习区状态行。

## 4. UI 响应性（设计目标，非墙钟实测）

| 场景 | v3.35.2 及以前 | v3.35.3+ |
|------|----------------|----------|
| 切换到「分析」页 | UI 线程同步跑引擎 + 读库，易冻结 1–5s | 仅触发异步刷新，切页 <50ms 量级 |
| FAIL 页 2000+ 条 | 同步 `AllFails` 阻塞 | 后台加载，首屏先显示旧数据 |
| 搜索框连续输入 | 每次键入全量过滤 | 250–300ms 防抖 |
