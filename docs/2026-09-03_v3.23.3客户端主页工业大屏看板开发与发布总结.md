> **文档定位**：记录 2026-09-03 完整的会话沟通、功能落地设计、自检自动化编写、全链路质量验证及发布准备细节。

## 1. 业务背景与用户需求

在数字化车间与产线高强度运行环境下，产线工程师和车间大屏监控人员对主程序客户端（`Argus.exe`）首页提出了更高要求：
1. **去班次化统一口径**：原有早班/夜班交接切换口径复杂且容易造成跨日数据失真，现场急需以**当日自然日（00:00~24:00）**为基准的高可靠、全天候综合看板。
2. **小时级负荷与质量监控**：需要掌握 24 小时连续生产走势（各小时 PASS/FAIL 柱状分布以及良率波动曲线），以及 98% 质量预警标线。
3. **产能与良率双指标大屏直观展示**：双环同心仪表盘（产能达成环 + 综合良率环），具备大字号与动态变色特性，远距离可视。
4. **缺陷聚焦 Top 排行**：按频次聚合当日高发故障项（Top 5），通过柱状排行与占比进度条快速指导现场巡检与维修方向。
5. **异常实时播报流**：实时滚动展示最新 10 条 FAIL 异常信息，支持鼠标交互并一键下钻至 FAIL 明细及真实 XML 测试日志。
6. **视觉与交互要求**：占满主页下半区（2×2 充满式自适应网格），支持明亮/暗黑双模式，GDI+ 高帧率自绘且彻底杜绝窗体闪烁。

## 2. 核心架构与技术实现

本次升级围绕数据持久层、UI呈现层、自检验证层进行了端到端全链路落地：

### 2.1 UI 呈现层自绘组件 (`FctAggregator/Ui/DashboardWidgets.cs`)
全部自绘控件采用 GDI+ 原生渲染，开启双缓冲（`OptimizedDoubleBuffer | AllPaintingInWmPaint | UserPaint`），完美契合零第三方 UI 依赖原则，深度适配 `Theme.cs` 双色令牌：

1. **`HourlyTrendChart`（小时产量与良率走势图）**：
   - 24 小时横轴（00:00 至 23:00）；
   - 左纵轴为产量负荷（自动计算上限阶梯），绘制 PASS（绿色）与 FAIL（红色）的堆叠柱状图；
   - 右纵轴为良率（0%~100%），绘制平滑青蓝色良率走势线与红色 98% 警戒虚线；
   - 鼠标 Hover 动态计算当前柱状位置，支持局部 Invalidate 脏矩形驱动的轻量级 Tooltip 浮层。
2. **`TodayGaugePanel`（当日产能与质量双环仪表盘）**：
   - 外环（产能环）：根据目标产能（默认 1000 pcs）计算完成进度弧，环心居中展示今日总产出；
   - 内环（良率环）：根据综合良率动态变色（≥98% 绿色、≥95% 黄色、<95% 红色），环心展示良率百分比与不良发生数；
   - 支持窗体缩放自适应半圆/圆弧居中自适应缩放。
3. **`TodayFailRankPanel`（当日 Top 5 故障不良项排行榜）**：
   - 纵向展示 Top 5 缺陷测项；
   - 前三名配备金、银、铜工业徽章标色，带平滑渐变进度条展示该测项在今日所有失败中的百分比；
   - 自动适配长名称文本截断与右对齐频次/百分比数值排版。
4. **`LiveAlertPanel`（实时异常告警与动态播报流）**：
   - 卡片式瀑布流展示最新 10 条不良异常；
   - 包含异常发生时间（高精度提取）、机台号、产品 SN、具体故障项（高亮红色）；
   - 绑定鼠标悬停微光效果与点击事件，支持跨模块跳转。

### 2.2 数据持久层高速聚合 (`FctAggregator/Db/Database.cs`)
为了支撑大屏的高频定时刷新与毫秒级查询，在本地 SQLite 数据层实现了 3 项聚合查询方法：
1. `FetchDailyHourlyStats(string stationId, string dateYmd)`：
   - 按 `strftime('%H', test_time)` 分组统计 00~23 小时的 `pass`、`fail`、`total` 与 `rate`，空缺小时自动补齐 0 记录。
2. `FetchDailyTopFails(string stationId, string dateYmd, int limit = 5)`：
   - 按失败原因字段 `fail_reason` 进行分组与 `COUNT(*)` 降序统计，计算总失败数占比。
3. `FetchRecentFailAlerts(string stationId, int limit = 10)`：
   - 按记录主键倒序直接提取最新 10 条 `result = 'FAIL'` 记录，返回结构化模型供告警流渲染。

### 2.3 主窗口布局重构与联动 (`FctAggregator/Ui/MainForm.cs`)
- 将主页下半区改造为充满式的 `TableLayoutPanel`（2 列 × 2 行，各占 50% 宽与 50% 高）；
- 左上放置 `HourlyTrendChart`，右上放置 `TodayGaugePanel`，左下放置 `TopFailRankPanel`，右下放置 `LiveAlertPanel`；
- 接入 10 秒定时刷新机制与 `OnThemeChanged` 响应回调，实时重新抓取数据库并重绘大屏；
- 实现 `LiveAlertPanel` 点击联动逻辑：点击异常卡片后，主窗体自动切换到「FAIL 记录」Tab，并自动筛选对应工件定位详情。

### 2.4 前端细节修复
- 修正了 `FctAggregator/public/js/page-alerts.js` 中 `new Event("change")` 的小括号缺失；
- 修复并恢复了 `core.js`、`loader.js` 中的部分乱码字符与标准化注释。
