# Argus 聚合服务 v3.8.0 使用说明
## 这是什么
多机台 FAIL 聚合服务。**v3.5.0 起是 P2P Mesh 架构**：每台机台运行同一个 Argus（每个都是一
「Mesh 节点」），互相推送 FAIL / 心跳数据；**没有专用聚合机** —— 任选一台机器（或专门一台大屏机）
执行 `Argus.exe agg --web` 就能作为**看板宿主**，浏览器打开 Web 看板查看各机台在线状态和
FAIL 明细，支持 XML 报告在线查看 / 下载、文件浏览和 CSV 导出。

> - 机台软件（采集 + 推送）和聚合服务（看板宿主）是**同一个程序、同一个安装包**，只是运行参数不同，
>   所以不存在"装混"问题。
> - 聚合看板也**内嵌进机台主程序**：机台侧边栏「工具箱 → 聚合看板」直接点开看板窗口，切走后台继续收数据。
> - Web 看板有**「设置」页签**（管理后台）：端口 / 令牌 / 飞书告警 / 汇总间隔全部可视化开关，
>   不用再手改 config.json（端口类改动需重启聚合服务生效）。

## 一键部署看板宿主（推荐）
1. 把 Argus 解压到看板机（任意目录，如 `D:\ArgusAgg`）
2. 双击「一键部署聚合服务.bat」，UAC 弹窗点"是"
3. 自动完成：
   - 生成 `config.json`（已存在则保留现有配置，不覆盖；**新装自动生成随机 agg_token**）
   - 防火墙放行 **8081** 端口（规则名 `ArgusAggWeb`，仅内网网段 10.x / 172.16-31.x / 192.168.x / 169.254.x，
     且仅 private/domain 网络配置放行）
   - 添加开机自启（启动文件夹快捷方式，不写注册表，杀软不会误报）
   - 启动聚合服务（后台无窗口常驻）
4. 部署窗口会打印访问地址（带 `?token=`），用浏览器打开 `http://本机IP:8081/` 即可查看看板

## 手动启动与停止
- 启动：命令行 `Argus.exe agg --web`（前台常驻），或双击一键部署 bat（后台）
- 停止：Ctrl+C 或关闭窗口
- 查看服务状态：浏览器打开 `http://127.0.0.1:8081/api/health`
- 数据在 `data\mesh_agg.db`（聚合副本库），运行日志在 `logs\`

## 端口说明（v3.8.0 已对齐）
- Mesh 节点 / Web 看板统一监听 **`mesh_port`，默认 8081**。
- 改端口：改 `config.json` 的 `mesh_port` 后重启；或 Web「设置」页「监听端口」改完重启生效，
  防火墙规则在重启部署时按新端口重建。
- 旧文档里的 `agg_http_port`（8080）是 v3.5.0 前中心化模式的遗留字段，**现在不再决定看板监听端口**。

## 机台端怎么接入
在每台机台的 `config.json` 里加 `peers`（其余配置保持不动），然后重启机台软件：

```json
{
  "agg_enabled": true,
  "peers": ["http://聚合机台IP:8081/"]
}
```

把 `聚合机台IP` 换成看板宿主机 IP（端口若改过，和 `mesh_port` 保持一致）。
配好后，机台每出一条 FAIL 就会实时推送给所有 peer；断网自动缓存（落盘）、恢复后补推，不用人工干预。
各机台之间还会每 30 秒对账一次（Gossiper），补上断线期间漏掉的数据。

> **更简单的做法**：机台主程序底部状态栏点「聚合设置」→ 填聚合端 IP 和端口（默认 8081）→
> 点「连接」即可，推送器自动重启生效。

## 文件浏览 / 下载说明
- Web 看板顶部有「看板 | 文件」页签：文件页可以浏览和下载测试报告（XML）
- `config.json` 里的 `results_root`（默认 `D:\Results`）是**文件白名单根目录**：
  XML 报告下载和文件浏览都只能看这个目录里的文件，目录之外一律拒绝（返回 403）
- 要改目录：改 `config.json` 的 `results_root`，然后重启聚合服务

## 可选：访问令牌（agg_token）
产线内网人多想加个锁时，聚合端和每台机台的 `config.json` 配**同一串** `agg_token`：
- 机台端：配好后推送自动带令牌，不用管
- 浏览器访问：地址栏加 `?token=同串`，如 `http://192.168.1.100:8081/?token=abc123`
- 不匹配/不带的一律 403；不配 = 不鉴权（兼容旧部署）
- **一键部署新装时自动生成随机 token**（部署窗口会打印带 `?token=` 的访问地址）；
  首次用 `?token=` 打开后浏览器会记住（HttpOnly Cookie），之后翻页/下载不用再带 token

## 可选：飞书离线告警 + 定时汇总
看板宿主 `config.json` 配 `agg_webhook_url`（飞书群机器人 webhook）后：
- 机台离线（心跳超时 90s）→ 飞书群即时告警卡（机台名 + 最后确认时间，同机台 10 分钟防抖）
- 每 `agg_summary_minutes`（默认 60）分钟 → 各机台汇总卡（在线/离线、累计 FAIL、心跳时间）

## 跨机台 XML 报告下载
机台端推送 fail 时自动把 ≤512KB 的 XML 一并上送，聚合端存 `data\agg_xml\{机台}\{seq}.xml`，
Web 看板「报告」列可直接下载**任意机台**的 XML。超过 512KB 的报告走按需拉取：看板向源机发起
HTTP 请求实时取（源机离线则该报告暂不可用）；也支持聚合机本机 results_root 白名单下载。

## 常见问题
| 问题 | 原因 / 处理 |
|---|---|
| 浏览器打不开看板 | 服务没启动：重新双击一键部署 bat，或手动运行 `Argus.exe agg --web` |
| 办公室电脑访问不到 | 防火墙未放行，或部署时没以管理员运行：重新双击一键部署 bat（UAC 点"是"） |
| 端口被占用 | 改 `config.json` 的 `mesh_port`（如 8082）后重启服务，防火墙规则会自动按新端口重建 |
| 某台机台数据一直不出现 | ①机台能 ping 通聚合机台 IP ②`peers` 的 IP/端口填对（默认 8081）③聚合服务已启动 ④重启机台软件 |
| 文件页看不到 / 下载 403 | 目标文件不在 `results_root` 目录内，聚合服务只放行白名单目录 |
