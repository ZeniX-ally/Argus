# FCT 不良项排名导出工具 (FCT-FailRanker)

一个独立的小工具：导出用户自定时间段内的所有 FCT XML 测试结果，汇总成 CSV / Excel，
并对该时间段内的**不良项按出现次数排名**（总排名 + 按型号 + 按机台）。

当前版本：**v1.5.0**（C# / .NET 8 WinForms，零第三方依赖）

## 功能

1. 选择结果目录（默认读取同目录 `config.json` 的 `results_root`，否则 `D:\Results`）
2. 选择起始/结束日期（按目录日期 `yyyyMMdd` 过滤，含结束当天）
3. 点【扫描统计】：递归扫描 XML，界面实时显示排名预览与概览，进度条 + 日志逐条输出
4. 右上【型号】下拉框：切换查看"全部型号"或某个型号的独立排名，右侧同时显示该型号
   的不良累计次数、占总不良比例、FAIL 台数、良率
5. 左侧文件夹结构树：惰性加载浏览 `results_root` 目录
   - 双击目录：展开 / 收起
   - 双击 `.xml`：弹出**报告式查看器**（深色仪表盘风格：SN 标题栏 + 状态徽章 + KPI 卡 +
     信息网格 + 全部测试项表格，失败项标红，被排除项标注"不计入不良"）
   - 双击其它文件：用系统默认程序打开
6. 三种导出：
   - 【导出 Excel(含分组排名)】4 Sheet
   - 【导出完整 CSV】概览 + 排名 + 分组排名 + 明细
   - 【仅排名表 CSV】只要排行榜，便于直接贴报告

## Excel (.xlsx) 导出

零依赖生成标准 OOXML，含 4 个 Sheet：

- **总排名**：概览 + 全局不良项排行
- **各型号排名**：按型号分组，组内各自排名（组间按 FAIL 台数降序）
- **各机台排名**：按机台(TESTER)分组，组内各自排名
- **明细清单**：全部记录明细

数字写为真数值（可直接在 Excel 里求和/做图），表头加粗。

## CSV 报表结构（完整导出）

- **概览**：有效记录总数 / 产品数(SN去重) / PASS / FAIL / 中断 / 良率 / 不良项累计次数
- **不良项排名(总)**（按出现次数降序）：排名 / 名称 / 出现次数 / 受影响产品数 / 占比%
- **按型号分组排名**（多型号时）：每个型号内部各自排名
- **按机台分组排名**（多机台时）：每个机台内部各自排名
- **明细清单**：每条记录的日期/类别/型号/SN/机台/结果/失败项列表/文件名

CSV 为 UTF-8 BOM 编码，Excel 打开中文不乱码。

## 业务规则（与主项目 Argus 一致）

- 分类看文件名前缀：`P_`=PASS、`F_`=FAIL、`O_`=中断
- 中断细分：`O_` 有真实 fail 项 → 记为 FAIL，无 → INTERRUPTED
- 不计入不良的失败项（包含匹配、忽略大小写）：
  - `Get Unit Information`（获取单元信息失败，不上传 MES）
  - `UUT Status Err`（被测单元状态错误，非产品真实不良）
- `USER=debug`（忽略大小写）的数据跳过不统计
- 型号目录校验：只扫 `E` + 7 位数字的型号目录（如 `E3002781`），与主项目
  `StationDetector.IsValidModel` 口径一致
- 型号取 SN 前 8 位；良率 = PASS /(PASS + FAIL)，中断不计入分母
- PASS 文件仅轻量读 USER 判 debug（性能优化），F_/O_ 深度解析收集失败项

## 目录结构约定

```
{results_root}\{Online|Offline}\{型号}\{yyyyMMdd}\{前缀_Fts_PEU_G49_机台_SN_时间_时间.xml}
```

## 源码结构

| 文件 | 说明 |
|------|------|
| `Program.cs` | 入口 |
| `MainForm.cs` | 主窗口：目录/日期/扫描/导出、排名列表、型号下拉、文件夹树、日志 |
| `XmlScanner.cs` | 目录扫描 + BATCH 格式 XML 解析 + 分类 + 失败项收集（含排除规则） |
| `CsvExporter.cs` | 聚合(总/按型号/按机台) + CSV 导出（完整 / 仅排名） |
| `XlsxExporter.cs` | 零依赖 OOXML 生成，4 Sheet |
| `XmlViewerForm.cs` | 深色仪表盘风格 XML 测试报告查看器 |
| `make_icon.py` | 生成 `app_icon.ico` 的脚本 |

## 构建 / 运行

```bash
dotnet build -c Release
# 运行: bin\Release\net8.0-windows\FCT-FailRanker.exe
```

前置：机台需安装 **.NET 8 Desktop Runtime**（框架依赖发布，`SelfContained=false`）。
